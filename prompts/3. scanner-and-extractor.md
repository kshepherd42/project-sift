Implement an independently testable binary JSON document scanner and property-path extractor.

Before coding

Inspect the existing repository conventions and reuse the existing DocumentResult, PropertyPath, ExtractionDiagnostic, DocumentStatus, and DocumentType types.
Do not modify existing contracts unless a concrete incompatibility prevents implementation. Report such incompatibilities instead.
Keep changes limited to the extraction component and its relevant xUnit tests.

Implementation

Accept raw bytes and scan the entire payload for candidate top-level JSON objects and arrays, including multiple documents surrounded by arbitrary binary framing.
Implement a small deterministic boundary scanner. Respect nested braces/brackets, JSON strings, escaped quotes, and backslashes. Never treat delimiters inside strings as structural boundaries.
Validate candidates using System.Text.Json. Do not decode the entire payload as UTF-8 and assume it is JSON.
Extract property paths recursively. Use dot notation for ordinary names, [] for array traversal, and the existing bracket-quoted escaping convention for names containing reserved characters. Preserve casing, deduplicate paths per document, and sort ordinally.
Support top-level objects and arrays. Return DocumentType.Unknown for failed candidates whose type cannot be established.
Use Successful for valid original documents, Recovered only for documented deterministic repairs, and Failed for unusable discovered candidates.
Recover incomplete fragments only when the boundary and repair are unambiguous. Never invent properties or values. Record each repair in a diagnostic. If safe recovery cannot be justified, return a failed result.
Return a separate DocumentResult for each discovered candidate, with stable diagnostic codes and useful byte positions where possible. A payload with no discovered candidates must remain distinguishable from one containing failed candidates.
Isolate candidate failures so malformed input cannot crash processing or prevent later independent candidates from being scanned.
Bound candidate size and nesting depth using minimal, configurable or clearly defined limits. Avoid unnecessary payload copies, dependencies, abstractions, and logging of raw content.
